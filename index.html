1. Classifique cada coluna

Para cada coluna do arquivo, escolha o que ela representa. Colunas marcadas como "Telefone" terão os caracteres não numéricos removidos e o DDI 55 adicionado (se ainda não tiver). Colunas marcadas como "Ignorar" são mantidas como extras no arquivo final, sem tratamento. azul = mapeamento lembrado de uma importação anterior. laranja = detectado como Aquisição ID já pronta (phone_email).
