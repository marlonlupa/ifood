1. Classifique cada coluna

Para cada coluna do arquivo, escolha o que ela representa. Colunas marcadas como "Telefone" terão os caracteres não numéricos removidos, o DDI 55 adicionado (se ainda não tiver) e o nono dígito "9" inserido quando faltar. Colunas marcadas como "Ignorar" são mantidas como extras no arquivo final, sem tratamento. Colunas marcadas como "Excluir" não aparecem no arquivo final. azul = mapeamento lembrado de uma importação anterior. laranja = detectado como Aquisição ID já pronta (phone_email).

2. Monte o Aquisição ID

Marque quais colunas (já tratadas, se telefone/email) devem compor o ID, na ordem desejada. Ex: telefone_new + email. Se você tiver uma coluna marcada como "Aquisição ID pronta", essa etapa é ignorada automaticamente. O Aquisição ID sempre usa o telefone e email completos (nunca zerados), pois é a chave única do registro. Já a coluna "phone" do arquivo final só fica preenchida na primeira linha que também tiver e-mail junto (linhas com telefone sozinho, sem e-mail, nunca recebem o telefone). A coluna "email" segue a mesma lógica de primeira ocorrência.
